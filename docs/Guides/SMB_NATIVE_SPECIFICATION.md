Данный документ представляет собой функциональную спецификацию встроенного Native SMB (SMB1/CIFS) клиента в Movian.

---

## 1. Спецификация конфигурации и настроек (Configuration Specs)

Native SMB клиент использует глобальные системные настройки Movian и Keychain (хранилище ключей) для авторизации на удаленных серверах.

### 1.1. Параметры авторизации Keychain
Данные авторизации сохраняются в Keychain по ключу вида `smb:connection:<hostname>:<port>` (`src/fileaccess/smb/fa_nativesmb.c:649`).

| Поле данных | Тип | Формат | Описание |
|---|---|---|---|
| `username` | Строка | UTF-8 | Имя пользователя для NTLMv1 авторизации. |
| `password` | Строка | Пароль | Пароль пользователя. |
| `domain` | Строка | UTF-8 | Домен сети (по умолчанию `WORKGROUP`). |

## 2. Спецификация поддерживаемых операций VFS (VFS Operations Specs)

В отличие от read-only клиентов, Native SMB клиент в Movian поддерживает как чтение, так и запись:

| Функция VFS | SMB1 Команда PDU | Описание |
|---|---|---|
| `smb_open` | `SMB_NT_CREATE_ANDX` (0xa2) | Открывает или создает файл на сервере. |
| `smb_close` | `SMB_CLOSE` (0x04) | Закрывает открытый файловый дескриптор. |
| `smb_read` | `SMB_READ_ANDX` (0x2e) | Читает данные из файла. Поддерживает параллельные асинхронные запросы (до 56KB на запрос). |
| `smb_seek` | Внутреннее смещение | Изменяет текущую позицию чтения/записи в `smb_file_t`. |
| `smb_fsize` | — | Возвращает `sf->sf_file_size`, сохранённый при открытии. Запроса в сеть не делает. |
| `smb_stat` | `SMB_TRANS2` (0x32) / `TRANS2_QUERY_PATH_INFORMATION` (5) | Возвращает метаданные файла/директории (размер, mtime, тип контента). |
| `smb_unlink` | `SMB_DELETE_FILE` (0x06) | Удаляет файл с сервера. |
| `smb_rmdir` | `SMB_DELETE_DIR` (0x01) | Удаляет пустую директорию с сервера. |
| `smb_scandir` | `SMB_TRANS2` (0x32) / `TRANS2_FIND_FIRST2` (1), `TRANS2_FIND_NEXT2` (2) | Сканирует директорию на сервере. |
| `smb_set_xattr` / `smb_get_xattr` | `SMB_TRANS2` (0x32) / `TRANS2_SET_PATH_INFORMATION` (6) | Запись и чтение расширенных атрибутов файлов (используется для хранения метаданных медиатеки). |
| `smb_enum_servers` | `SMB_TRANSACTION` (0x25), RAP NetServerEnum2, function code 104 (`fa_nativesmb.c:2799`) | Перечисляет доступные SMB-серверы в рабочей группе (локальном сетевом окружении). |

## 3. Спецификация трансляции статусных кодов ошибок (Error Mappings)

Серверные ответы с ошибками SMB1/NT-класса преобразуются в коды возврата Movian VFS с помощью функции `check_smb_error`:

| Код ошибки SMB1 (DOS / NT Status) | Код возврата VFS | Описание |
|---|---|---|
| `ERRbadfile` / `STATUS_OBJECT_NAME_NOT_FOUND` | `ENOENT` | Файл или путь не найден. |
| `ERRnoaccess` / `STATUS_ACCESS_DENIED` | `EACCES` | Доступ к ресурсу запрещен. |
| `ERRfilexists` / `STATUS_OBJECT_NAME_COLLISION` | `EEXIST` | Файл уже существует. |
| `ERRbadpath` / `STATUS_OBJECT_PATH_NOT_FOUND` | `ENOENT` | Неверный сетевой путь. |
| `ERRbadshare` / `STATUS_BAD_NETWORK_NAME` | `ENODEV` | Сетевой ресурс (шара) не существует. |
| `ERRtoo_many_ur` / `STATUS_TOO_MANY_OPENED_FILES` | `EMFILE` | Превышен лимит открытых файлов на сервере. |

## 4. Системные лимиты и ограничения (System Limits)

* **Максимальный размер блока асинхронного чтения:** `57344` байт (56KB) на один запрос `SMB_READ_ANDX` (0x2e) согласно ограничениям протокола SMB1.
* **Таймаут сетевых запросов:** `15000` мс (`NBT_TIMEOUT`).
* **Периодичность проверки соединения (Heartbeat / Echo):** `15` секунд (`SMB_ECHO_INTERVAL`). Отправляет пустой запрос эхо для поддержания сессии активной.
