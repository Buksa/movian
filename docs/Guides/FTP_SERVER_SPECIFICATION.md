## 1. Спецификация настроек (Configuration Specs)

Настройки FTP-сервера хранятся в базе данных Movian в домене `ftpserver`.

| Ключ настроек | Тип настроек | Значение по умолчанию | Диапазон / Формат | Функция-обработчик | Описание |
|---|---|---|---|---|---|
| `ftpserver.enable` | `SETTING_BOOL` | `0` (Выключен) | `0` или `1` | `set_enable` | Активация/деактивация FTP-сервера. |
| `ftpserver.port` | `SETTING_STRING` | `"2121"` | TCP Порт (`1`–`65535`) | `set_port` | Порт прослушивания командного канала FTP. |
| `ftpserver.username` | `SETTING_STRING` | `""` (Анонимный) | Строка UTF-8 | `set_username` | Логин пользователя. Если пуст, разрешен анонимный доступ. |
| `ftpserver.password` | `SETTING_STRING` | `""` (Пустой) | Скрытая строка (Password) | `set_password` | Пароль пользователя для авторизации. |

## 2. Спецификация поддерживаемых команд FTP (RFC 959)

Ниже перечислены поддерживаемые команды командного канала FTP-сервера Movian:

| Команда | Функция-обработчик | Требует авторизации | Описание |
|---|---|---|---|
| `QUIT` | `cmd_QUIT` | Нет | Завершает текущую сессию и закрывает соединение. |
| `USER` | `cmd_USER` | Нет | Устанавливает имя пользователя сессии. |
| `PASS` | `cmd_PASS` | Нет | Проверяет пароль и авторизует сессию. |
| `SYST` | `cmd_SYST` | Нет | Возвращает тип операционной системы (`UNIX Type: L8`). |
| `FEAT` | `cmd_FEAT` | Нет | Перечисляет поддерживаемые расширения (возвращает `SIZE`, `UTF8`). |
| `TYPE` | `cmd_TYPE` | Да | Устанавливает тип передачи: `A` (ASCII) или `I` (Image/Binary). |
| `PWD` | `cmd_PWD` | Да | Выводит текущую рабочую директорию. |
| `CWD` | `cmd_CWD` | Да | Изменяет рабочую директорию. Пути резолвятся относительно корня VFS. |
| `PASV` | `cmd_PASV` | Да | Переводит сервер в пассивный режим (открывает случайный порт данных). |
| `LIST` | `cmd_LIST` | Да | Передает список файлов директории через канал данных. |
| `SIZE` | `cmd_SIZE` | Да | Возвращает точный размер файла в байтах. |
| `RETR` | `cmd_RETR` | Да | Скачивает файл с VFS сервера (чтение файла). |
| `STOR` | `cmd_STOR` | Да | Загружает файл на VFS сервера (запись файла). |
| `MKD` | `cmd_MKD` | Да | Создает новую директорию на сервере. |
| `DELE` | `cmd_DELE` | Да | Удаляет указанный файл. |
| `RMD` | `cmd_RMD` | Да | Удаляет указанную директорию. |
| `RNFR` | `cmd_RNFR` | Да | Запоминает исходный путь для операции переименования файла. |
| `RNTO` | `cmd_RNTO` | Да | Выполняет фактическое переименование файла/директории из пути `RNFR`. |
| `OPTS` | `cmd_OPTS` | Нет | Обрабатывает опции команд (например, `OPTS UTF8 ON`). |

## 3. Таблица статусных ответов FTP (FTP Response Codes)

Сервер отвечает стандартными трехзначными кодами FTP:

* `150 File status okay; about to open data connection.` — готовность открыть порт данных.
* `200 Command okay.` — команда успешно обработана.
* `213 File status.` — возврат размера файла.
* `220 Service ready for new user.` — приглашение к авторизации на сервере.
* `221 Service closing control connection.` — успешный выход из сессии.
* `226 Closing data connection.` — успешное завершение передачи файла или списка.
* `230 User logged in, proceed.` — успешная авторизация.
* `250 Requested file action okay, completed.` — действие завершено (CWD, удаление).
* `257 "PATHNAME" created.` — вывод рабочей директории или создание папки.
* `331 User name okay, need password.` — имя пользователя принято, ожидается пароль.
* `350 Requested file action pending further information.` — получен исходный файл для переименования (RNFR).
* `425 Can't open data connection.` — сбой открытия пассивного порта.
* `530 Not logged in.` — сессия требует авторизации.
* `550 Requested action not taken.` — файл не найден, или нет прав доступа.

## 4. Ограничения и лимиты (System Limits)

* **Максимальная длина командной строки:** `1024` символа (размер буфера команд в `ftp_session`).
* **Управление портами данных (Passive Mode):** Порт данных выделяется динамически ядром ОС при связывании `bind()` сокета с портом `0`.
* **Символы конца строки (EOL):** Зависят от режима `TYPE`:
  * Режим `A` (ASCII) преобразует концы строк к стандарту `\r\n`.
  * Режим `I` (Binary/Image) передает файлы в исходном виде без модификации концов строк.
* **Таймаут сокетов:** Контролируется вызовами чтения и записи TCP сокетов Movian `tcpcon_t`.
